# Workflow: Comprehensive Workspace Cleanup and Repair

Description:  
Perform a deep cleanup and repair of the entire workspace. This workflow deletes junk files, removes unused dependencies, fixes broken imports and errors, optimizes structure, and restores consistency across configs and settings.

Steps:  
1. Delete temporary files, caches, build artifacts, and all junk safely.  
2. Remove dead code, unused dependencies, and orphaned files.  
3. Fix broken imports, unresolved references, syntax errors, and config misalignments.  
4. Optimize folder and file structures for best practices.  
5. Clean workspace metadata and settings for consistency.  
6. Preserve essential source code and assets only.  
7. Verify safety before deleting or modifying critical items.  
8. Generate a summary report detailing all changes.

Execute methodically and confidently to restore a pristine, error-free workspace.
