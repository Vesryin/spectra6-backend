# 🌌 Spectra6 Windows Setup Scripts

Welcome to **Spectra6** – your cyberpunk-powered backend & frontend setup for Windows.  
All scripts feature **neon ASCII dashboards, colored step-by-step logs, and cyberpunk aesthetics**. ⚡🎶

---

## ⚡ Cyberpunk Dashboard Cheat Sheet

| Script | Purpose | Status |
|--------|---------|--------|
| `spectra6_windows_all_in_one.ps1` | Clone/update backend, install Python venv & dependencies, deploy backend/frontend | ⚡ Ready |
| `spectra6_windows_complete.ps1` | Complete setup including PostgreSQL user/db & pgvector placeholders | 🔥 Ready |
| `spectra6_windows_portable.ps1` | Fully portable: runs from folder/USB with no system installs | ⏳ WIP |

> 💡 **Tip:** All scripts print a **neon-colored ASCII dashboard** when launched in PowerShell or Git Bash.

---

## 🚀 Quick Launch Instructions

1. Open **PowerShell as Administrator**.  
2. Allow script execution:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

3. Run your desired script:



# All-in-one setup
.\spectra6_windows_all_in_one.ps1

# Complete setup
.\spectra6_windows_complete.ps1

# Portable setup
.\spectra6_windows_portable.ps1


---

🛠 Requirements

Windows 10+

PowerShell 5+

Internet connection (for downloading dependencies)

Admin privileges recommended

🔐 Notes & Security

Default database credentials are for automation only – change in production.

Logs are saved as timestamped .log files in the script folder.

Railway & Vercel credentials prompted by scripts.

💡 Tips

Use complete script for zero-touch fresh machine setup.
